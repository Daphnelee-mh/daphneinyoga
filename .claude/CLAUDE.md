# Working rules for daphneinyoga.com

This repo is published live by GitHub Pages: anything that reaches `main` goes live on daphneinyoga.com.

## Git and pull requests

- **Always ask before merging a pull request.** Never merge a PR (including squash, rebase, or auto-merge) until Daphne has explicitly said yes in the conversation for that specific PR.
- Never push directly to `main`. Make changes on a new branch and open a pull request instead.
- After opening a PR, share the link and a short summary of what changed, then wait for approval before merging.
- Approval for one PR does not carry over to any other PR.
